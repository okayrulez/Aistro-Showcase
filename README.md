# Aistro

A mobile application that lets prospective parents explore dates and locations according to astrological birth-chart preferences.

I developed the application and its supporting web and data workflows.

**Technologies and areas:** mobile development, Cloudflare D1, SQLite, date and location calculations.

**Websites:** https://aistro.tr · https://aistro.com.tr

Astrological preferences are the application's subject matter; they are not scientifically established predictions about a child's traits.

This repository introduces the project. Application source code is private.
